# The Pico Ipod
> The Pico Ipod is a recreation of the apple Ipod, parts being soldered onto the PCB. 

# Files
> `BOM.csv` outlines the billing cost of the project if you were to build it.
> `./src` is the source files for the C++ code for the Ipod, and can be built from the main directory with ```cmake -G Ninja -DPICO_BOARD=pico ..
ninja```
> `./PCB` contains the PCB files (made in KiCAD).



# The Pico 2W Music Player
> The Raspberry Pi Pico 2W Music Player is a project based on the apple ipod - a handheld battery-powered music player.

## Why Did I Create This Project?
> All of the current music players on the market are either **stupidly expensive, bad quality, or low storage** with little to no upgrading. Due to this, I wanted to create such a project, creating my own handheld music player instead of using my phone's battery on music.
