# The Pico 2W Music Player
The Raspberry Pi Pico 2W Music Player is a project based on the apple ipod - a handheld, battery-powered music player.

## Why Did I Create This Project?
> All of the current pocket music players on the market are either **stupidly expensive, bad quality, or low storage** with little to no room for upgrading. Due to this, I wanted to create such a project, creating my own handheld music player instead of using all my phone's battery on music. This project was also something interesting to get into, being my first ever hardware project.
